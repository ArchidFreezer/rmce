◆ tokenise()

std::vector< std::string > tokenise ( const std::string & text,
const std::string & delimiters = " " )

Split a string into tokens on one or more delimiters.

The delimiters argument may consist of multiple characters each of which will be used as a delimiter, for example using the text string "Test 1,string 1,Test 2,string 2:Test 3:string 3" and delimiters ",:" would return an array of the following:

  • Test 1
  • string 1
  • Test 2
  • string 2
  • Test 3
  • string 3
Parameters
textString to split
delimitersString containing the character(s) to use as tokens
Returns
vector of the tokens
