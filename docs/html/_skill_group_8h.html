◆ SkillGroup

enum class SkillGroup
strong

Enumeration class representing groups of skill categories.

Skill groups are used to group together skill categories (#SkillCategory) and have minimal in-game impact. The one area where there is the possibility for their use is in training packages (#TrainingPackageData) where a pack could allow a character to allocate some ranks into a skill category or skill of the players choice in the group, though this is rare.

std::optional< SkillGroup > fromString ( std::string_view sv)
constexpr

Get the enumeration value based on a string.

Accepts values that are returned by toString() in a case insensitive manner.

For values that contain strings with a space or slash this function will accept these with the character, with the character removed or with the character changed to an underscore:

  • "scienceanalytic"
  • "science analytic"
  • "science_analytic"
  • "science/analytic"
