enum class SkillDevelopmentType
strong

Enumeration class representing number of skill ranks gained for each rank purchased.

When purchasing ranks in a skill the number of ranks actually gained depends on whether the skill is treated as special for the character. Certain races and professions have affinities or aversions to specific skills which modify the number of skill ranks gained for each onew purchased.

You cannot develop part of a rank and you must spend enough points to gain a full rank.

Enumerator
kEveryman 

For every rank developed, the character gains two ranks

kOccupational 

For every rank developed, the character gains three ranks

kRestricted 

For every two ranks developed, the character gains only one rank

kStandard 

For every rank developed, the character gains one rank
