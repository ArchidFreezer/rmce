Detailed Description

template<typename MatcherClass, typename MatcherDatatype, typename CellDatatype, typename ColumnType>
requires is_row_matcher<MatcherClass, MatcherDatatype>
class LookupTable< MatcherClass, MatcherDatatype, CellDatatype, ColumnType >

Base class representing a lookup table index by row and column.

Each row is indexed using a matcher class MatcherClass that adheres to the is_matcher concept that matches on the datatype MatcherDatatype. When performing a lookup on the table the class will iterate through the rows until it finds a matcher that matches and then from the associated row retrieves the data value of type CellDatatype based on a lookup in the column matcher.

The column matcher is added via the setColumnMatcher() method which must becalled prior to attempting to retrieve data from the table and must be of class TableColumnMatcher. Prior to any call to retrieve cell data this must be set to the appropriate value for the type defining the columns, which are typically enumerations.
