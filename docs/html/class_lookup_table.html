Detailed Description

template<typename MatcherClass, typename MatcherDatatype, typename CellDatatype>
requires is_row_matcher<MatcherClass, MatcherDatatype>
class LookupTable< MatcherClass, MatcherDatatype, CellDatatype >

Class representing a lookup table index by row and column.

Each row is index using a matcher class T that adheres to the is_matcher concept that matches on the datatype U. When performing a lookup on the table the class will iterate through the rows until it finds a matcher that matches and then from the associated row retrieves the data value of type V.

Template Parameters
MatcherClassMatcher that is used to identify the correct row
MatcherDatatypeData type that the matcher MatcherClass matches on
CellDatatypeData type that is stored in each cell in the table
