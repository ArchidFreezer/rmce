Detailed Description

Contains the SkillDevelopmentType enum and associated functions.

When purchasing ranks in a skill the number of ranks actually gained depends on whether the skill is treated as special for the character. Certain races and professions have affinities or aversions to specific skills which modify the number of skill ranks gained for each onew purchased.

You cannot develop part of a rank and you must spend enough points to gain a full rank.
