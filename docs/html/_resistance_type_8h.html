std::optional< ResistanceType > fromString ( std::string_view sv)
constexpr

Get the enumeration value based on a string.

Accepts values that are returned by the toString() in a case insensitive manner.

For values that contain strings this function will accept these with the space, with the space removed or with the space changed to an underscore:

  • "ChannelingEssence"
  • "Channeling_Essence"
  • "Channeling / Essence"
  • "Channeling Essence"
