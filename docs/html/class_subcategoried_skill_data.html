Detailed Description

Wrapper class for a Skilldata object that allows for a specific skill subcategory to be defined.

This is typically referenced in classes that are used for character development such as races or professions where they need to be able to set modifiers on specific subcategories of a skill. An example would be that the Dwarf race sets the Survival skill as everyman, but only for the underground subcategory.

The subcategory is optional to allow this wrapper to be used for skills that do not have subcategories or the modifier is for all subcategories of the skill.
