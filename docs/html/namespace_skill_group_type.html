Detailed Description

Contains the SkillGroupType::Type enum and associated functions.

Skill groups are used to group together skill categories (SkillCategory) and have minimal in-game impact. The one area where there is the possibility for their use is in training packages (TrainingPackageData) where a pack could allow a character to allocate some ranks into a skill category or skill of the players choice in the group, though this is rare.
