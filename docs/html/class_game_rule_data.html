Detailed Description

Polymorphic class that is the base for objects that store data on the rules of the game.

This class is used as the base for all classes that contain objects with data for the game rules, e.g. Professions, Languages, Skills, etc.

Get the unique id of the game data object.

Each object containing game rule data requires a unique identifier to allow it to be referenced. Having this virtual method in this base class ensures that all derived classes have to provide one.
