Detailed Description

template<typename T>
requires std::integral<T> || std::floating_point<T>
class NumberRange< T >

Stores a range of contiguous numbers allowing checking against another number.

This class is a basic building block for the game lookup tables which typically have rows based on ranges of dice rolls. The row indexes may be stored in this class and then the actual rolls compared to the range to determine the correct row to use

Template Parameters
TNumber type, which can be either an integral or floating point
