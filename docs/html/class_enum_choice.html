Detailed Description

template<typename EnumType>
class EnumChoice< EnumType >

Class representing a choice that a player has available from a set of Enum objects.

There are several times, especially during character development, where a player must select one or more options from a set of options. This class defines the options available and the number that may be selected.

The class is not meant to be prescriptive on the relationship between the number of choices and the options available so for example it may be used for defining one or more skills from a skill category that a member of a race may select as everyman skills, or it may be used to define a number of skill ranks that may be distributed amonst a set if skills for a profession or traning package.
