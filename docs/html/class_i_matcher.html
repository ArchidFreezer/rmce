Detailed Description

template<typename T>
class IMatcher< T >

Interface that defines a method that determines if the class matches a value.

This class is primarily used as a key in lookup table rows that allows the table to determine if the row is the one to use for a given input value

Template Parameters
TNumber type, which can be either an integral or floating point

virtual bool IMatcher< T >::matches ( T val) const

Determines if the value is considered a match for the class.

A use case is where a value needs to be checked against a range of values such as in a lookup table where the same row is applicable for mulitiple values. In that case the table may use a class that implements this for the key to each row to prevent duplication of the rows.
