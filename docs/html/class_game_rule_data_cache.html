Detailed Description

Class to store game rule data, such as profession definitions, spell lists, etc.

The class is thread safe and can cache any object type that is derived from the polymorphic GameRuleData class

The game rule data that is stored must be passed as a unique_ptr which ensures that there is only a single copy and it is the cache that owns the object. This ensures that all objects are correctly
