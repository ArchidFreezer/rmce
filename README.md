# Rolemaster Character Editor

# Overview
This repository contain the code and data that will be used to crerate an application to create and maintain rolemaster characters.

# Standards
The standards used are based on the google coding standards avaiualbel on their own github site: [C++](https://google.github.io/styleguide/cppguide.html), [JSON](https://google.github.io/styleguide/jsoncstyleguide.xml)
I do not slavishly follow these, but use them when I have no personal preference. As is common nowadays I have wide screen monitors and like to see more code on screen so do not have line wrapping set to split lines at specific character counts. The exception to this are comments where I wrap at 123 characters.

One area where this project differs is the naming of functions where lowerCamelCase is used in preference to the Google UpperCamelCase standard.
In case where this creates awkward or difficult to read values snake_case is acceptable.
